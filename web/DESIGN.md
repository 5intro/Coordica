# 已批准视觉

2026-10-15 用户批准首页交互样稿接入正式版。米白背景、墨褐文字与原版衬线 Coordica 字标保留古典感；主操作松石青。亮柠檬绿只保留样稿已确定的 Dock 当前玻璃底座及人工待办强调，不增加面积或新增用途。原 favicon 不改。中文内容采用系统字体，无新字体、图标或动效依赖。

首页四池两列两行，每行池保持相同高度，默认约两到三项的密度，显示实际总数；完整活动卡片可在池内上下滚动。池名在凹槽外上方，点击直接进入完整池；没有重复“查看全部”。浅米灰凹槽通过轻度内阴影与底沿反光下沉，左上沿接近右下的淡度。事项是玻璃片，用透色、边缘高光与软投影区分，不用实线逐项描边。标题、状态、简要来源或执行者构成每条预览。完整标题、原始需求、摘要、固定版本及证据可在详情查看，不用省略数据伪造状态。

首页人工待办无事项隐藏；有事项显示首项、总数及完整处理入口。主机区显示真实活动运行，能力探测不算运行实例，最后上报不推断永远在线；未知主机或失联未静止实例保留。超出首页容量的主机和运行提供完整管理入口。

# 共享组件

`components/material` 只负责玻璃、图标、Dock 与非模态详情容器，不知道任务授权和 API。`Overview` 及 `WorkItemPanel` 消费 Snapshot；业务动作复用原页面、ApiClient、useAction。`RequirementComposer` 在首页和需求页共享校验、请求及失败保留逻辑。样稿只消费同一材质，不将演示数据导入正式页面。

Dock 图标、选中底座共用缩放抬升，邻项让位，整体玻璃舒展；使用稳定槽位计算距离，避免变形后的尺寸反馈造成抖动。左右键、Home/End、清晰焦点及 aria-current 保留。各尺寸八入口 Dock，不再重复工作池切换，正文留出底部空间。

详情以概览、动态、关联分段降低密度，支持关联返回、Escape 关闭和源焦点恢复；记录从新快照消失时移除旧内容，提示核对完整页面。完整操作及深链接、筛选、历史导航仍保留。技术 ID 与完整证据放在默认关闭的技术详情中。系统与项目开关仍需真实保存并显示错误、未保存和生效状态。

# 玻璃取样

只折射背景，文字与控件保持稳定。采用向内连续位移，边界取样变化更慢并平滑过渡到中心，避免折返造成条纹；圆角裁切外延续法线场，平滑位移图并校正中性通道。相同尺寸共用有限缓存，指针移动不逐帧重建。Chromium 增强折射，其他引擎保留独立的 CSS 磨砂回退。不能将组件测试或 CSS 存在作为 Safari/Firefox 光学实测证明。

遵从系统 reduced-motion；取消空间变形但保留状态、焦点和操作反馈。玻璃动态验收需观察背景从直边及圆角滑过的过程，静态截图不能代替该检查。

# 其他页面

完整池继续提供搜索、筛选、排序、历史与可复制深链接。需求、任务和审查的浏览列表使用相同简洁卡片，范围、预算与授权操作留在详情。设置使用成组真实控件，测试中心按套件、记录和就绪分区；技术输出按需展开。取消、停止证明、固定候选版本及测试缺失不绿的语义不因简化而改变。


行高与页首：四池按两组行组织，每行底部有低干扰拖拽分隔条，同一行的两个池同步调整，卡片独立滚动不带动页面。支持方向键、Home 恢复默认、End 最大、双击复位；高度仅存本机浏览器，与后台策略无关。页首只保留 Coordica 字标和搜索，移除“协作工作台”副标题。


池页页首：删除重复的需求／任务／审查／阻断切换条；“全部／活动／历史”位于各池标题同一行，新增操作留在该行右侧，窄屏必要时只将操作换行。底部 Dock 在小屏保持全部八个去向，避免删除重复导航后丢失入口。

完整池页保留左侧单列玻璃事项列表、右侧固定证据面板；不将列表改成两列卡片墙，不复用首页浮层来承载完整页面。长证据与长列表独立滚动并避开 Dock；700px 以下按上下排列。Agent 页的主机、Agent、接到的任务是三列对应关系，编辑器在宽屏右侧，窄屏置后。模型、强度及调度表单使用现有色彩与控件，不新增装饰色或图标。
