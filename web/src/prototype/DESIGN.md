# 首页交互样稿

范围：Operate。仅首页、Dock、详情面板的独立样稿；未替换正式工作台。

入口：`web/prototype.html`。运行现有 Vite 开发服务器后打开 `/prototype.html`。

## 已确认方向

- 用户确认保留现有玻璃、动效与交互，要求规划一套清新、醒目、高饱和与高对比的配色，避免多色滥用。
- 以 Superlist、Craft 的内容组织与色彩作为参考，Dock 与面板保持连续层次。
- 首页四池具体列表、主机 Agent 动态、人工待办；底部 Dock。
- 不引入假操作系统、交通灯、窗口拖拽或常驻侧栏。
- 系统字体适配中文，普通列表不展示 UID。恢复阶段 A 最早的衬线 Coordica 字标和小方点；favicon 直接复用同一版本的原文件。

## 样稿视觉

统一使用「米白、墨褐、松石青、柠檬黄」。用户要求米白背景带一点 Claude 官网的古典感；保留原有衬线字标，以暖中性色承接玻璃，不复刻其品牌。颜色按用途分配，四池不再各自占据一个主色。四池各有完整的凹槽容器，以浅暖灰米色底、上沿内阴影和下沿反光表现下沉；每个事项是放在槽内的独立玻璃片，以透色、柔和投影和渐变边缘高光表现厚度，不再用实线逐项描边。首页默认约两到三张的高度，卡片在池内滚动且计数保留全量，完整池、搜索、关联中的事项同样使用玻璃卡片。

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 米白 | `#f5f2eb` | 主画布 |
| 白色 | `#ffffff` | 玻璃高光与内容清晰度，不作为不透明卡片铺满 |
| 墨褐 | `#302d27` | 标题、正文、关键导航 |
| 松石青 | `#007566` / `#006655` | 主操作，及运行中、审查和通过的高对比字色 |
| 柠檬黄 | `#ddf34b` | 当前 Dock 选中与小面积重点 |
| 琥珀 | `#8c5803` / `#f8ebcb` | 等待与需要方案 |
| 红色 | `#b42b38` / `#fbe4e5` | 阻断与决策 |
| 次要文字 | `#71695e` | 来源、主机、时间 |
| 池底 | `#e7e1d6` / `#eee9e0` / `#f3eee6` | 凹槽的连续同色明暗与深度 |
| 边框 | `#dcd5c9` | 仅确有必要的控件与分隔，池和事项卡片不描线 |

字色与米白画布对比 12.27:1；次要文字与白色 5.41:1、与米白底色 4.84:1；主按钮白字 5.62:1；柠檬黄上的深字 9.58:1；三种状态标签文字均不低于 5:1。背景、交互、边框与字色的用途分层参考 [Radix Colors](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale)，本表色值是本样稿的选择，不宣称官方整套配色。

Dock 不再使用八种糖果色或图标渐变；仅当前选中有柠檬黄玻璃底座。事项卡片没有逐项图标，池标题使用文字。图标保留在 Dock、搜索、关闭、新建、主机等关键操作与实体。Agent 使用简洁的字母身份块。

字标复用 `5e2f129` 中的 `'Lyon Text', Georgia, serif`、32px、400 字重、原字距与 `#71806a` 小方点。没有重新设计标志，也不增加字体依赖。卡片标题 14px、次要状态 11px、页标题 28–33px。三个外观选项仅调整同一配色里的底色浓淡：米白、亚麻、暖瓷。

## 交互与材质

- 圆角透镜法线编码为 Canvas 位移图，SVG `feDisplacementMap` 作用于背景，不变形文字。
- 事项玻璃卡片复用同一材质组件，折射开关在首页、完整池、搜索、关联中一致。尺寸相同的透镜位移图复用，缓存有上限，不逐帧重建贴图。
- Chromium 使用增强折射，其他浏览器回退至真实磨砂玻璃；不能声称已完成 Safari / Firefox 实测。
- Dock 以未变形槽位计算指针距离；图标与选中的玻璃底座共用缩放、抬升及横向位移。相邻项自然让位，外层玻璃随整体伸展，离开与窗口变化时复位；键盘聚焦同样可体验，减少动态效果时取消空间变形。每次指针事件最多更新一个动画帧，只改变变换参数，不重建透镜贴图。
- 详情面板进入与退出、分段切换、关联跳转、Escape 关闭与焦点返回。
- 外观可切换环境色、折射和动态效果；尊重系统减少动态效果。
- 搜索含无结果状态；新增需求含必填校验；页面中的决定只改变演示数据。
- 有限的任务流转演示：开发 → 自测 → 预合并检查 → 审查池。可暂停与重播。

## 玻璃下方流动的材质要求

用户补充：玻璃质感应来自下方颜色真实透出；背景滑过玻璃边缘时，呈现更强的弯折与阻尼观感，接近真实玻璃边缘的反射、折射。

- 中心透色与边缘折射必须有差异，不能让整块背景均匀模糊或均匀平移。
- 边缘取样采用随距离变化的非线性位移，强化圆角与厚边的挤压、放大和滑过边缘时的视觉滞留。
- 随背景的相对移动实时更新取样；高光、折射与背景运动保持一致。
- 不用整体拖慢卡片动画或额外拖延输入来伪造该效果；文字与按钮保持稳定清晰。
- 材质验收要观察背景从固定玻璃下方滑过的过程，检查中心、直边和圆角，静态截图不能代替动态验收。
- 当前版本已有非线性位移图与卡片透色；上述边缘流动观感仍须专项对照验证，不因存在 CSS 或 SVG 参数就宣称完整复现。

## 数据与边界

所有主机、Agent、任务、时间和测试结果均为明确标识的演示数据。没有 API 客户端、模型调用或真实任务派遣；需求与决定只保存在页面内存，刷新重置。仅外观偏好存入独立 localStorage 键。正式中心、Runner、现有样式、数据库与授权逻辑不变。

用户确认效果后再决定正式接入；不将样稿作为后端验收证据。


## 正式接入确认

2026-10-15：用户批准该样稿接入正式工作台。保持亮绿色数量与面积；池名移到凹槽上方，直接作为完整列表入口，删除重复的“查看全部”。池底进一步调浅，左上内阴影减至接近右下的轻度。材质组件、Dock 与图标提取到 components/material，样稿和正式页面共同使用；演示数据与演示流程仍只存在于独立样稿。

位移场改为向内、连续且不折返的边缘取样，直边边界的相对取样变化率约 0.04，向中心平滑恢复到 1；圆角裁切外延续同一法线场，取样图平滑并校正中性通道。该参数表达空间压缩观感，不伪造输入延迟，也不能替代动态浏览器观察。


行高与页首：四池按两组行组织，每行底部有低干扰拖拽分隔条，同一行的两个池同步调整，卡片独立滚动不带动页面。支持方向键、Home 恢复默认、End 最大、双击复位；高度仅存本机浏览器，与后台策略无关。页首只保留 Coordica 字标和搜索，移除“协作工作台”副标题。
