# 已确认产品事实

Coordica 是单项目中心协调分布式 Runner 的开发工作台。首页服务于日常推进工作（Operate），所有状态来自现有 Snapshot，不产生新授权或状态转换。

首页页内包含项目名、已保存目标、按任务已集成数量计算的进度、暂停状态及提交需求入口。人工待办仅呈现实际需要批准、决策或停止核验的记录，无事项时整区隐藏。需求、任务、审查、阻断四池每池最多展示五条活动事项、活动总数及完整池入口。需求无独立状态字段，活动需求定义为尚无关联任务或仍有关联非终态任务。

审查池复用 candidates 的真实 ID 和固定 commit；prechecking 尚未进入 Agent 审查，reviewing 为待审或审中，后续门禁及待集成候选仍可见。历史失败和已合并候选不进入活动列表，不虚构 ReviewTask。

主机动态按 nodes 与 runs.node_id 分组，只展示实际活动 Run（含未确认静止的失联 Run）。能力探测不是运行实例或认证证明；最后上报时间不是永久在线证据。未知主机 ID 的活动 Run 仍须可见。

现有初始化、规划、自动化、审计、恢复与设置保持可发现入口；测试中心由后续工作台整合任务接入。本任务不修改 App、API 或后台。
